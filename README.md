# منظومة العمل التنفيذي — محافظة حلب

نظام موحّد لإدارة المهام والاجتماعات والقاعات والصلاحيات والإشعارات.
واجهة عربية كاملة من اليمين لليسار · خادم Next.js · قاعدة بيانات MongoDB.

**تصميم وتنفيذ: ProoTech Agency**

---

## ١ — التشغيل السريع

```bash
npm install
```

### أ) اضبط ملف البيئة

أنشئ ملف `.env.local` في جذر المشروع (انسخ `.env.example`):

```ini
MONGODB_URI="mongodb+srv://USER:PASSWORD@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority"
MONGODB_DB="governorate"
SESSION_SECRET="مفتاح-عشوائي-طويل-غيّره"
SEED_PASSWORD="Aleppo@2026"
# المساعد الذكي — مفتاح من console.anthropic.com (اختياري: بدونه يعمل كل شيء عدا المساعد)
ANTHROPIC_API_KEY="sk-ant-..."
```

> **مهم:** لا تشارك هذا الملف ولا ترفعه إلى Git — هو مستثنى أصلاً في `.gitignore`.

**للحصول على رابط Atlas:** لوحة تحكم Atlas ← `Connect` ← `Drivers` ← انسخ الرابط،
ثم استبدل `<password>` بكلمة مرور مستخدم القاعدة. وتأكّد من السماح لعنوان IP جهازك في
`Network Access`.

### ب) افحص الاتصال

```bash
npm run db:check
```

### ج) عبّئ قاعدة البيانات

```bash
npm run seed
```

يُنشئ الجهات والقاعات والتكليفات والاجتماعات والمراسلات و**٢٠ حساب مستخدم** بكلمة
مرور مشفّرة، ويطبع قائمة أسماء الدخول. ولإعادة البناء من الصفر:

```bash
npm run seed:fresh
```

### د) شغّل النظام

```bash
npm run dev
```

ثم افتح `http://localhost:3000` وسجّل الدخول.

## ٤ — الأمن

- كلمات المرور مخزّنة بـ **bcrypt** ولا تُحفظ نصاً أبداً.
- الجلسة **JWT موقّع** داخل كعكة `httpOnly` تنتهي بعد ثماني ساعات، ولا يستطيع
  جافاسكربت في المتصفح قراءتها.
- `proxy.ts` يمنع الوصول إلى أي صفحة أو مسار API بلا جلسة صالحة.
- **الترشيح يجري على الخادم:** مسار `bootstrap` لا يرسل أصلاً ما لا يملك المستخدم
  صلاحية رؤيته — إخفاء العناصر في الواجهة ليس هو الحماية.
- كل تغيير حالة يُفحص في `canAdvance` على الخادم ويُرَد برسالة عربية واضحة عند الرفض.
- الملفات والمراسلات تُحجب حسب **درجة التصريح** (عادي / هام / سرّي / سرّي للغاية).
- **سجل التدقيق** يسجّل كل دخول وكل إجراء باسم صاحبه، ولا يملك أي دور حذفه.

## ٥ — قاعدة بيانات محلية للتطوير (اختياري)

إن أردت العمل بلا إنترنت أو بلا Atlas:

```bash
node scripts/dev-db.mjs      # اتركها تعمل في نافذة مستقلة
```

ثم اضبط في `.env.local`:

```ini
MONGODB_URI="mongodb://127.0.0.1:27017/"
```

البيانات تُحفظ في مجلد `.mongo-data` داخل المشروع.

## ٦ — النشر

```bash
npm run build
npm start
```

قبل النشر على خادم حقيقي:

1. غيّر `SESSION_SECRET` إلى قيمة عشوائية طويلة.
2. غيّر كلمات مرور الحسابات.
3. شغّل خلف HTTPS (الكعكة تُرسل بخاصية `secure` تلقائياً في وضع الإنتاج).
4. قيّد وصول قاعدة البيانات إلى عنوان الخادم فقط في `Network Access`.

## ٨ — القرارات المعتمدة من مكتب السيد المحافظ

هذه القرارات مطبَّقة في النظام فعلياً، ومفروضة **على الخادم** لا في الواجهة فقط.

| البند | القرار | أين طُبِّق |
|---|---|---|
| صلاحية الاعتماد | السيد المحافظ ونوابه فقط | `canApproveDecision` — مدير المكتب والأمين العام يُرفضان برسالة صريحة |
| نائب المحافظ | كامل الصلاحيات | جدول الأدوار — كل الإجراءات مفتوحة |
| معاون المحافظ | يعتمد ويتابع، بلا حذف نهائي | دور `assistant` |
| الأمين العام | تنظيم ومتابعة وأرشفة، بلا اعتماد | دور `secgen` |
| مدير المكتب | اطلاع وترتيب ومتابعة، بلا اعتماد ولا إغلاق | جدول الأدوار |
| مهلة العاجل والعاجل جداً | رد خلال 24 ساعة | `slaHours` وقواعد التصعيد |
| مهلة الهام | 48 ساعة كحد أقصى | `slaHours` |
| التكليف العادي | جدول زمني يُحدَّد عند الإسناد | حقل `scheduleDays` |
| إشعار المراجعة | عند انتهاء المدة يصل إشعار لمُصدِر التكليف ليراجع المكلَّف | `lib/review.ts` — يعمل تلقائياً عند كل تحميل |
| أولوية القاعات | المحافظ ← النائب ← المعاون ← الأمين العام ← المدراء المركزيون | `bookingLadder`، وتظهر في شاشة القاعات |
| مؤشرات الالتزام | معتمدة رسمياً في التقييم والقرار الإداري | منوّه عليها في شاشة مؤشرات الأداء |
| نطاق المرحلة الأولى | سبع مديريات مركزية + ثلاث مناطق | `lib/seed.ts` |
| المناطق | تل رفعت · عفرين · الباب | دور `area` |
| الأحياء | الجميلية · العزيزية · الخالدية | دور `area` — نوع الجهة «حي» |
| الشكاوى | خارج نطاق هذا النظام | لا وجود لها في أي شاشة |
| الاستضافة | داخل مبنى المحافظة — غرفة العمليات جاهزة | `MONGODB_URI` يوجَّه إلى الخادم الداخلي |
| كلفة الرسائل النصية | على المحافظة | قناة الرسائل مفعّلة للعاجل جداً |
